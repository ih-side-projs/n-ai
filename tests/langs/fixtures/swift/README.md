# Captured Swift/XCTest output samples

These files are **hand-captured samples** of Swift 6.0 / Xcode 16 output for
`swift build` and `swift test`. They are not generated by this repository: no
Swift toolchain is installed in the environment where they were added, so the
parser tests that use them are labelled `captured-sample` and only pin the
formats the adapter relies on (`error:` lines, `Fatal error: not implemented`,
`Test Case '...' passed|failed`, `Executed 0 tests`).

When a real toolchain is available, re-capture each case and diff:

| File | Command | Exit | What it pins |
|------|---------|------|--------------|
| `build_error.txt` | `swift build` | 1 | located `error:` diagnostics |
| `stub_crash.txt` | `swift test` on a `fatalError` stub | 132 | abort marker, no test result |
| `test_pass.txt` | `swift test` | 0 | `Test Case ... passed`, `Executed 1 test` |
| `test_fail.txt` | `swift test` | 1 | `Test Case ... failed`, `XCTAssert` error line |
| `zero_tests.txt` | `swift test --filter NoSuchTests` | 0 | `Executed 0 tests` |

The capture host was macOS 15 on arm64 with Swift 6.0 (Xcode 16); paths are
shortened to `/Users/dev/TinyLibrary` so the samples stay readable.
