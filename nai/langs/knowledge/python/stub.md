The contract stub is generated by the pipeline; keep its shape when implementing.

Shape (Python 3.12)

```python
from __future__ import annotations


def normalize(text: str) -> str:
    """Collapse whitespace."""
    raise NotImplementedError("Contract stub for normalize")
```

Rules
- Keep the module path `src/<package>/<module>.py` and the exact function names and signatures.
- Keep `raise NotImplementedError(...)` until the behaviour exists: the pipeline proves tests fail against the stub before implementation.
- `from __future__ import annotations` comes first; module-level imports are standard library only unless a pinned package is required.
- No import-time side effects: no I/O, no network, no mutable global state.
- `entities.py` holds the `@dataclass` entity records; other modules import from it.
- Do not add public functions the contract does not list; tests import only contract names.
- Docstrings are one imperative line ending with a period.
