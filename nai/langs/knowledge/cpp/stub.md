The contract stub is generated by the pipeline; keep its shape when implementing.

Shape (C++17)

```cpp
// include/word_counter/word_counter.h
#ifndef NAI_WORD_COUNTER_H
#define NAI_WORD_COUNTER_H

#include <string>

namespace word_counter {
int count(const std::string &text);
}

#endif  // NAI_WORD_COUNTER_H
```

```cpp
// src/word_counter/word_counter.cpp
#include "word_counter/word_counter.h"
#include <stdexcept>

namespace word_counter {
int count(const std::string &text) {
    throw std::logic_error("not implemented");
}
}
```

Rules

- Keep the header's declarations and the source's signatures; tests call them.
- Contract stubs throw `std::logic_error("not implemented")`.
- The build must succeed with the stub; the test run throws (valid stub failure).
- `CMakeLists.txt`, `vendor/` and `include/entities/` are adapter-owned.
- Integration nodes export `int integrate();`.
- Do not add public API the contract does not list.
