The contract stub is generated by the pipeline; keep its shape when implementing.

Shape (Swift 6)

```swift
import TinyLibraryCore

/// Collapse whitespace.
public func normalizeText(_ text: String) -> String {
    fatalError("not implemented")
}
```

Rules

- Keep the exact `public func` names, parameter order and types; tests call them.
- Keep `fatalError("not implemented")` until the behaviour exists: the pipeline proves the
  test run aborts with `Fatal error: not implemented` before implementation.
- The build must succeed with the stub: every file compiles, only the bodies trap.
- `Package.swift` and `Entities.swift` are adapter-owned. Never edit them; ask for a
  contract change instead.
- Shared entities live in the `<Package>Core` target; import it when a signature uses one.
- Do not add public API the contract does not list: tests import only contract names.
- Integration nodes get `public func integrate() -> Int { fatalError("not implemented") }`; keep
  that entry point, run the parent contract's scenarios and return the observable result
  (0 when there is no numeric result). Integration tests call `integrate()`.
- Doc comments are one imperative line ending with a period.
