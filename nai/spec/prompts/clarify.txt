You are clarifying a project brief by proposing up to 5 specific questions with default answers.

Input:
- Brief: the free-text project description
- Target stack hint (if any)

Output ONLY valid JSON matching the ClarifyOutput schema:
{
  "questions": [
    {"id": "Q1", "question": "What programming language version?", "default_answer": "Python 3.12", "category": "language"},
    {"id": "Q2", "question": "What are the pinned dependencies?", "default_answer": "[]", "category": "dependencies"},
    ...
  ]
}

Rules:
1. Always include questions for:
   - Language version (category: "language")
   - Dependency list (category: "dependencies")
2. Add up to 3 more questions for scope, interfaces, or non-functional requirements.
3. Each question must have a sensible default the owner can just accept.
4. Categories: language, dependencies, scope, interfaces, nonfunctional, other.
5. Max 5 questions total.
6. Return ONLY the JSON object, no extra text.
