# version: 1
You are designing the interface contract for a decomposed system.

Input:
- Brief: the original project brief
- Approved component map: the selected DecomposeOutput (components, shared_entities, external_inputs, external_outputs)

Output ONLY valid JSON matching the InterfacesOutput schema:
{
  "contract": {
    "entities": [
      {"name": "EntityName", "description": "...", "fields": [{"name": "field", "type": "type", "description": "...", "optional": false}]}
    ],
    "components": [
      {"name": "component-name", "description": "...", "provides": [{"name": "func_name", "signature": "func_name(arg: Type) -> ReturnType", "description": "...", "returns": "ReturnType"}], "consumes": ["other-component"]}
    ],
    "scenarios": [
      {"id": "S1", "title": "Scenario title", "steps": [{"caller": "component-or-external", "callee": "component-or-external", "call": "func_name", "fields": ["Entity.field", "Entity.other_field"]}]}
    ]
  }
}

Rules:
1. Every shared_entity from the map must appear in contract.entities with all its fields.
2. Every component from the map must appear in contract.components.
3. For each component:
   - provides: list of functions it implements (name, signature, description, returns)
   - consumes: list of sibling component names it depends on (must match depends_on)
4. Scenarios: write end-to-end workflows covering the external_inputs -> external_outputs flow.
   - Each step MUST use exactly these four properties: caller (component id or "user"/"external"), callee (component id being called), call (exact function name with no parentheses), and fields (array of Entity.field references passed or produced). The JSON schema enforces this; any other property is rejected.
5. Every entity field consumed in a scenario must be produced by some component or be an external input.
6. Every entity field produced by a component must be consumed by another component or be an external output.
7. No dependency cycles among components.
8. Component names: lowercase-hyphenated. Entity names: PascalCase. Function names: snake_case.
9. Return ONLY the JSON object, no extra text.
